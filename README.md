# sweed-design — Claude Code mods

Marketplace `sweed-design`. Plugins:

| Plugin | What it does |
|---|---|
| [figma-task](plugins/figma-task/README.md) | Sets up a task page in the quarterly Figma file and works through its review comments. Install: [SETUP.md](plugins/figma-task/SETUP.md) |

```bash
claude plugin marketplace add https://github.com/riveones/figma-task.git && claude plugin install figma-task@sweed-design --scope user
```

Nothing personal lives here: designer emoji, Figma file keys and tokens stay in each person's plugin settings.
