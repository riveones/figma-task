# figma-task

Мод для Claude Code: собирает страницу задачи в квартальном Figma-файле и разбирает комментарии ревью. Ставится один раз и работает в любом репо — design-lab, `web-ui-shop` и других: экраны берёт из ветки, на которой вы работаете.

## Что делает

### Страница задачи — `/figma-task DP-2871` или «собери фигму для этой задачи»

Для Ecom — `/figma-task ECOM-15438 ecom`. Ключ задачи Claude возьмёт из просьбы или из имени ветки. После пуша ветки `feature/<KEY>-…`, у которой ещё нет страницы, Claude сам спросит: «Собрать страницу в Figma?». Ход работы видно в панели «Figma task».

| Шаг | Что получается |
|---|---|
| Страница | копия шаблона в квартальном файле с именем `🌙  DP-2871 – <название из Jira>`, сразу после шаблона |
| Jira-виджеты | ссылки на всю цепочку задачи до корня, по порядку, с кнопкой Copy — вставить в виджет (Import an issue or project) |
| Флоу | экраны и состояния, снятые Playwright и разложенные досками по сценариям: шаги, стрелки с действием, подписи. Источник — ветка, на которой вы работаете, как она есть сейчас, с незакоммиченными правками: прототип в design-lab, ветка `web-ui-shop` или другой репо; локально или на стенде. Если нужен вход — вы входите сами в открывшемся окне |
| For dev | экраны с жёлтыми пронумерованными рамками: для каждого элемента — компонент продакшн-кита, его пропсы и как то же сделано в проде. Portal — `@sweed/fe-portal-kit`, Ecom и CMS — `sd/web-ui-shop`. Клоны этих репо мод находит на машине сам |
| Перепроверка | второй агент независимо проверяет каждое сопоставление; исправления вносятся до показа |

### Комментарии из Figma — «проверь комментарии по DP-2871»

Или `/figma-comments DP-2871`.

1. Сам находит страницу задачи в Portal- и Ecom-файлах.
2. Читает открытые треды и показывает, к чему привязан каждый: текст, скриншот флоу, экран или маркер For dev.
3. Предлагает план правок таблицей и ничего не меняет до «да» — на весь план или на отдельные номера.
4. Правит: тексты и подписи, обновление UI задачи — правка кода в вашей ветке, пересъёмка и замена скриншотов в Figma. На вопросы и споры о решениях — только черновик ответа.
5. Готовит ответы в исправленные треды. Каждый ответ вы читаете в панели «Figma task» и отправляете своей кнопкой.

### Чего не делает

- Не закрывает треды и не отправляет ответы сам — это вы.
- Не привязывает Jira-виджеты — ссылку в виджет вставляете вы.
- Не заполняет «⏱️ Process / ⚠️ NOT FOR DEV»: скриншоты текущего продукта и рабочие заметки — ваши.

## Установка

**1. В терминале**, из любой папки:

```bash
claude mcp add --transport http --scope user figma-remote https://mcp.figma.com/mcp && claude plugin marketplace add https://github.com/riveones/figma-task.git && claude plugin install figma-task@sweed-design --scope user
```

**2. В `claude`:** `/mcp` → `figma-remote` → **Authenticate**.

Всё. На первой задаче мод спросит ваш эмодзи (любой, с которого не начинается ни одна страница файла) и файл текущего квартала — подскажет, какой искать по дате, — и запомнит оба на этой машине. Токен Figma — при первой проверке комментариев.

> Если съёмка пишет «Executable doesn't exist» — `npx playwright install chromium`. Обновить мод — `claude plugin marketplace update sweed-design && claude plugin update figma-task@sweed-design`.
